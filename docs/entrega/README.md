# Presentación de sustentación

Archivo: [Sustentacion_Analista_IA.pptx](Sustentacion_Analista_IA.pptx).

Ocho diapositivas con notas del presentador y referencias a los artefactos del
proyecto. La tabla de puntuación y los textos permanecen editables.

1. Objetivo de la solución.
2. Problema comercial y arquitectura.
3. Normalización, identidad y trazabilidad.
4. Extracción de conversaciones con evidencia.
5. Reglas de prioridad y ejemplo de score.
6. Comparación experimental con y sin pesos de clase.
7. Evidencia de integridad y aislamiento.
8. Demostración en vivo.

La URL proporcionada por el autor es
[la plataforma en Render](https://prueba-tecnica-analista-ia.onrender.com/).
**La primera carga puede tardar mientras Render inicia el servicio. Esperar a
que aparezca el inicio de sesión.** No se promete un tiempo fijo.

Las credenciales se comparten por un canal privado y no están en la presentación.
La demostración debe hacerse en la URL, como exige el enunciado. Abrirla con
anticipación y comprobar las cuentas y la disponibilidad de asesores para la cola.
La publicación comunicada por el usuario no acredita por sí sola un cron o worker
alojado; verificar esos procesos por separado.

Las cifras describen las pruebas y los datos del proyecto. El modelo tabular es
experimental y no se presenta como una mejora comercial demostrada.
